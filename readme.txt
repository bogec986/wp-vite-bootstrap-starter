Production-ready WordPress starter theme using Vite, Sass, Bootstrap 5, Fontsource, and Carbon Fields.

== Description ==

WP Starter is a development foundation for custom WordPress websites. It provides a modern Vite asset workflow, Bootstrap 5, Sass, Fontsource typography, optional Carbon Fields integration, accessibility-oriented markup, standard WordPress theme features, and a production build workflow.

== Installation ==

1. Upload the wp-starter theme directory to /wp-content/themes/.
2. Install PHP dependencies with Composer.
3. Install Node dependencies with npm install.
4. Run npm run build for production assets.
5. Activate the theme in Appearance > Themes.
